# Mare Liberum V22 — Name & Accessibility Settings

## Game identity
- Renames the game and main-menu presentation to **Mare Liberum**.
- Updates the window title, menu title, version information and player-facing documentation.
- Keeps the existing Python package and legacy save identifier intact so older V20/V21 `.tide` voyages remain loadable.

## Adjustable text
- Adds **Text & Display Settings** to the main menu.
- Text can be adjusted from 75% to 150% in 5% increments.
- Applies consistently to dialogue, menus, HUD, journal, help, maps and ledger fonts.
- Saves the preference automatically in `mare_liberum_settings.json` beside the game folder, independent of individual voyage saves.

## Player documentation
- Replaces the developer-oriented README with a player-facing guide covering installation, first voyage, world, story, activities, sailing, combat, fleet commands, controls and saves.
